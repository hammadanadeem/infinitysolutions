# Infinity Solutions — starter website

Responsive static HTML/CSS/JavaScript website for a digital services company.

## Before publishing
1. Open `index.html`.
2. Replace `REPLACE_WITH_YOUR_BUSINESS_EMAIL` in the script with an email address you control.
3. Test the contact form on desktop and mobile. The form opens the visitor's email application; it does not save submissions on a server.
4. Confirm the business name is available for registration, domain registration and social handles before making it permanent.
5. Add genuine portfolio examples only. Do not invent testimonials, client logos or results.

## Free hosting
Recommended: Cloudflare Pages. Create a Pages project and upload this folder or connect a Git repository. The free Pages subdomain will look like `your-project.pages.dev`. To use a root domain such as `yourbrand.com`, register that domain separately and connect it in Cloudflare Pages.

## Current scope
- Business website and custom development
- Shopify and WooCommerce
- AI Search Visibility (AEO/GEO)
- Technical troubleshooting

## Important limitations
The contact form uses `mailto:` and does not store leads. Add a form backend or form service later if you need server-side lead capture. AI search visibility improvements do not guarantee mentions, citations or recommendations by AI platforms.
